# Technical SEO Toolkit

A practical technical SEO toolkit focused on website indexing, crawlability, search visibility, and Google Search Console diagnostics.

## Overview

This project documents a structured approach to finding and fixing common technical SEO problems that can prevent pages from being discovered, indexed, or ranked correctly.

The main focus areas include:

- Google Search Console diagnostics
- Indexing issues
- XML sitemap validation
- robots.txt checks
- Canonical tag verification
- Redirect analysis
- Broken links
- Metadata checks
- Structured data review
- Crawlability and technical site health

## Google Search Console

Typical checks include:

- Page indexing status
- Crawled - currently not indexed
- Discovered - currently not indexed
- Duplicate pages
- Canonical conflicts
- Sitemap processing
- Coverage issues
- Performance trends
- Search queries and impressions

## Indexing

Technical checks may include:

- Indexability
- noindex directives
- Canonical URLs
- Internal linking
- HTTP status codes
- Duplicate pages
- Orphan pages

## XML Sitemaps

Review areas include:

- Valid sitemap URLs
- Correct HTTP responses
- Canonical URLs only
- Removal of redirected or broken URLs
- Sitemap submission status
- Last crawl information

## robots.txt

Checks include:

- Accidental crawl blocking
- Sitemap declaration
- Important path accessibility
- Search engine crawler rules

## Redirects

Review common problems such as:

- Redirect chains
- Redirect loops
- Incorrect 301 / 302 usage
- Broken destination URLs
- HTTP to HTTPS redirects
- www / non-www consistency

## Canonical Tags

Verify:

- Self-referencing canonicals
- Duplicate content handling
- Canonical consistency
- Canonical URLs matching indexable pages
